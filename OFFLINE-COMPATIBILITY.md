# DiamondBank-OG offline-player API compatibility

Covers `api/DiamondBankAPIKotlin` (K) and `api/DiamondBankAPIJava` (J). Async access off the main thread is assumed and is not a defect. Fully offline-safe and omitted: `diamondsToShards` and `shardsToDiamonds`, which touch no UUID, though they diverge (K returns a failed `Result`, J calls `getOrThrow` at `DiamondBankAPIJava.kt:339` with no `@Throws`, and `MoreThanOneDecimalDigitRuntimeException` extends the checked `DiamondBankException` rather than its sealed parent at `DiamondBankException.kt:21` to `:22`, so Java cannot compile a catch). `getBankShards` is Partial through the cross-cutting row alone, so it gets no row.
